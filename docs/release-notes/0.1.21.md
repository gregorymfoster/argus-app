- **No duplicate exports after a crash.** An export stopped at the wrong moment could write a Photo twice (a `-2` copy) or leave an empty file behind when it resumed. Both are fixed.
- **No duplicate copies after a crashed import.** A resumed Import no longer copies an original again as `-2` when it was already in place.
- **Background work runs once.** With `argus work` running beside the app, a job could run twice, and two quick requests could queue the same job twice. Each job now runs once, and work left by a killed process is picked up again within minutes.
- These fixes came from checking Export, Import and the Queue with formal models (TLA+), which now run on every change.
