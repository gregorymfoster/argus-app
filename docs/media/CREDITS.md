# README media

Screenshots and clips of the real app for the README, made with `prototype/scripts/readme-shots.mjs` and shrunk by `scripts/readme-media.sh`. Every photo in them comes from the release page's sample card: public-domain and CC0 photos from Wikimedia Commons, listed below with their sources. None are Greg's. `scripts/public-export` refuses any file in this folder that isn't named here.

Files: agent.webp, grid.webp, import.webp, presets.webp, stacks.webp, takes.webp
